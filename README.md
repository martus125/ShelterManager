# 🐾 ShelterManager

ShelterManager is a Java application designed to manage an animal shelter.

The application allows users to manage animals and shelter sectors, track animal health conditions, and monitor available space.

## Features
- Add, edit, and remove animals and sectors
- Move animals between sectors
- Track animal health conditions
- Search, sort, and filter animals
- Monitor sector capacity
- Save and load data (planned)

## Technologies
- Java
- Maven
- JavaFX (planned)
- JSON (planned)

## Project Structure
- `Animal` – stores animal information
- `AnimalCondition` – defines health conditions
- `ShelterSector` – manages animals within a sector
- `ShelterManager` – manages the entire shelter
